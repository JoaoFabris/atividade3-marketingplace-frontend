# Marketplace - Projeto React

## O que é React?

React é uma biblioteca JavaScript para construir interfaces de usuário (UI),
criada e mantida pelo Facebook (Meta). Em vez de manipular o HTML diretamente
como fazíamos com JavaScript puro, o React permite dividir a interface em
**componentes**: pedaços independentes e reutilizáveis de código que
representam partes da tela (um botão, um card de produto, um cabeçalho, etc).

## Por que usar React no front-end?

- **Componentização**: cada parte da tela vira uma peça isolada e reutilizável,
  o que facilita manutenção e organização do código.
- **Reatividade**: quando o estado de um componente muda (ex: um item é
  adicionado ao carrinho), o React atualiza automaticamente só a parte da
  tela que precisa mudar, sem precisar recarregar a página.
- **Ecossistema**: existem várias bibliotecas prontas para resolver problemas
  comuns, como o React Router para navegação entre páginas.
- **Popularidade e mercado**: é uma das tecnologias mais usadas no mercado
  atualmente, o que facilita aprendizado, suporte e oportunidades de trabalho.

## Estrutura do projeto

- `src/components/` → componentes reutilizáveis (Header, Footer, ProdutoCard...)
- `src/pages/` → páginas completas da aplicação (Home, Detalhes, 404...)
